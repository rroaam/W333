# Capsule (W333)

**A home-screen widget for time tracking and one-tap voice capture.**

Tap the widget, talk, and Capsule saves the thought with a timestamp. Designed for creatives who think out loud and lose ideas between tasks.

**Web:** https://capsule-web-psi.vercel.app

## Inside
- `Capsule/` · native iOS app (SwiftUI): recorder, playback, haptics, capture store
- `capsule-web/` · companion web app

## Run
Open `Capsule/Capsule.xcodeproj` in Xcode and run on device or simulator.

**Stack:** Swift · SwiftUI · WidgetKit
